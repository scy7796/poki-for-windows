# Security policy

Poki controls a real iPhone and sends screen contents to your configured model service. Report anything that could expose that access or those contents.

## Report a vulnerability

Report it through [GitHub private vulnerability reporting](https://github.com/scy7796/poki-for-windows/security/advisories/new). Do not open a public issue. If it also happens with Poki on macOS, report it to [Poki](https://github.com/JosssphZhou/poki/security/advisories/new) too.

Include the affected commit, the steps to reproduce, and the impact. Remove passcodes, tokens, and private screen contents from what you send.

## Supported versions

Security fixes go to the latest commit on `main`.
