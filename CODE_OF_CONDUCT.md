# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository and wherever you represent the project.

To report a problem, use [GitHub private vulnerability reporting](https://github.com/scy7796/poki-for-windows/security/advisories/new) and start the title with "Conduct". The maintainers review each report and keep the reporter's identity private.
